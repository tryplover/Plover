Plover, direction A: Dots

Round 2 mascot concept. A bird built from one to four soft dots that float, merge, split and re-form.

Rationale. Voice-assistant dots feel alive because nothing ever snaps: everything eases, breathes and melts into its neighbour. Dots borrow that, then use the arrangement of a few blobs to suggest a bird: a big dot with a small one on top becomes a body and a head, a single blob that hops reads as a little sparrow. Each state is told through rhythm alone (a sequential bob for listening, a slow shared breath for working, a burst and regroup for celebrating), so it still reads at 40px where no detail survives. Colour shifts are soft and secondary; nudges use warm apricot and never red.

How I'd build it for real. Ship it as code-driven SVG (or a tiny canvas), not Lottie. Each variant is a pose function pose(state, t) → dots[] and transitions are a 0.7s eased blend from the current frame to the new pose, which is exactly the idle / working / … state interface the spec asks for, and it makes interrupted transitions free. The goo merge is one SVG blur + alpha-threshold filter. If the art team wants hand-authored timing later, Rive's state machine is the natural upgrade path since it handles blended state transitions natively; Lottie is a poor fit because it can't blend between loops mid-flight.

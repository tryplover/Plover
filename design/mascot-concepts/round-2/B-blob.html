Plover · Direction B: “Blob”

Rationale

Plover should be a soft little shape you want to look at, not a detailed illustration. One squishy body and two eyes give us the fewest parts that can still feel alive, and that is what keeps it readable at 40px and quiet beside real work. All the personality comes from the eyes (blinks, glances toward your work, happy squints, sleepy lids) and from squash-and-stretch hops. The bird-ness is in the hop, the head tilt and, depending on the variant, a tuft, wing nubs or a beak nub. Every state shares one rig, so the three variants are reskins of the same animation interface.

How I'd build it

I'd use Rive. Its state machine maps one-to-one to the 8 states and blends between them, so we don't get the hard cuts that CSS loops make. A numeric input can drive the eye-glance direction toward the active window, and the runtime is small enough for an always-on-top Electron window. This page is a CSS/SVG prototype with one nested-group rig (hop › squash › tilt › face › eyes › lid), which carries straight into Rive bones. I'd skip Lottie because it has no state machine or input-driven blending.

This defaults to your OS prefers-reduced-motion setting. Each state keeps a static pose, and only fades remain.

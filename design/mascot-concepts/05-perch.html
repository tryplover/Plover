Perch: a small-first Plover

Concept 05. Drawn at 16px first, then scaled up. The bird sits on the edge of whatever UI it lives in.

Rationale. Plover spends most of its life at 16 to 32px, in a menu bar or perched on the overlay pill, so every variant here was drawn on a 16-pixel grid first and only then enlarged. At that size detail does nothing, but posture and timing read clearly. So each state is a pose: standing, pecking, hopping, looking up, or tucked away. The motion is a handful of held frames played with CSS steps(), never tweened, which stays crisp at any scale and echoes how a real plover runs, stops dead, and bobs. For privacy, "paused" always changes the silhouette as well as the color: the beak tucks away, the eye shuts, and in the menu-bar version the bird ducks below the edge entirely.

Plumage #7A4718 (brand) Face / belly #FFF8EE Collar / eye #2A1A0E Signal #E39A2D (progress + nudge only) Plumage, dark UI #C98B52 Face, dark UI #FFF1DE Signal, dark UI #F2B54F Light bg #F6F1E8 Dark bg #17140F

Core sprite is 3 colors. Amber is a 4th "signal" color that appears only during progress and nudge, so it always means something. On dark UI the palette swaps rather than inverts: the plumage lightens so the silhouette holds.

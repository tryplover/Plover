Proposal

The bird has a purpose

Usage open

Thinking, company and a little celebration.

  • One featured peek per view, with reserved space.
  • No bird over controls, dense text or the current task.
  • Keep the beak visible; no eye-only status icons.
  • Focus mode stays still and quiet.

Round buddy versus Puff stays a separate decision. See the context studies.

Motion and reduced motion

Breaking it into steps...

120 / 200 / 300 ms UI transitions. Gentle 4–6 second character loops if adopted; no decorative spring bounce. Reduced motion retains status text and a static bird.

The voice

Start: “Let's pick the first small step.”

Working: “A first draft is enough.”

Done: “That's one step done. Steady work.”

Error: “Couldn't save this task. Try again.”

No guilt, pressure, streaks or extra chatter. Custom voices stay deferred.

Accessibility behaviour

  • Visible focus; native control semantics.
  • Persistent labels and inline errors.
  • 44 px control height; 20 px icons.
  • Meaning from text and shape as well as colour.
  • Text reflows on narrow screens.
  • Dialogs contain focus and return it on close.

Contrast checks cover listed token pairs. An app accessibility audit follows implementation.

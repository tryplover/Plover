# Wordmark lockups — draft for review

Lowercase plover, outlined from the local Nunito variable font at weight 700.
Lexend remains the text face. No font installation is required to use the SVGs.

Horizontal: symbol 128 units; word silhouette 104 units high; gap 24 units.
Stacked: word width 248 units; symbol 128 units; gap 24 units.
Letter spacing uses font kerning, then additional pair adjustments in font units:
p–l −16, l–o −20, o–v −18, v–e −20, e–r −12. Glyph shapes are unmodified.

These proportions are proposed, not yet founder-approved.
Rebuild with: node design/wordmark-tools/build.cjs

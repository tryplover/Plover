# Feature: Advanced Inference & Nudge Engine v2

> Read [../overview.md](../overview.md) first.

Transform the Nudge Engine from a rule-based system into a proactive, AI-driven coach that leverages the full context of user activity and history.

## Scope

1. **Contextual Reasoning**: The Nudge Engine uses recent screenshots, window titles, and plugin data to understand *why* a user is off-track.
2. **Proactive Rescheduling**: Agent suggests specific calendar moves ("You're stuck on X, should we move the 3 PM block for Y to tomorrow?").
3. **Progress Synthesis**: Periodic (daily/weekly) summaries of goal progress generated by Gemini, delivered as native notifications.
4. **Natural Language Interaction**: Users can "talk back" to nudges to provide context or instructions.
5. **Mood/Focus Signals**: Inferring user state (e.g., "high focus", "distracted") to optimize nudge timing.

## Hard Constraints

- **Non-Intrusive**: Nudges must be easy to dismiss and respect "Deep Work" or "DND" states.
- **Privacy First**: Inference data used for nudges is processed locally or via the secure Gemini proxy, never stored on a central server.

## Implementation Order

1. Extend the `Nudge` module to accept richer context from `ActivityRepo`.
2. Implement the "Reasoning" pass using Gemini.
3. Add interactive notification actions (e.g., "Reschedule", "Dismiss").
4. Build the Daily/Weekly Summary generator.
5. Integrate with System Focus/DND modes.
